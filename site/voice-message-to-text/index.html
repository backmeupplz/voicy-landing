How to turn a Telegram voice message into text

Send the voice message to @voicybot in Telegram, or add the bot to a group and reply to the voice message with /transcribe. Voicy answers with the text a few moments later. There is nothing to install, and it also works on round video messages, audio files and videos.

As of November 9, 2026: Voicy is a separate bot, so you send the message to it, and each chat is activated once with a donation, because the speech recognition runs on GPUs we pay for. Until then Voicy answers with the donation options instead of the text. Telegram Premium has transcription built in, which needs no bot but a paid Telegram subscription.

Open in Telegram

In a private chat

  1. Open @voicybot in Telegram and press Start.
  2. Record or forward a voice message to it, or send it an audio file.
  3. Voicy replies with a status message that says it is turning the audio into text, shows a draft while it works, and then posts the final text. Text longer than 4,000 characters arrives as several messages.
  4. If the chat has not been activated yet, Voicy answers with the donation options instead. Send /donate to see them.

In a group chat

  1. Add @voicybot to the group.
  2. Choose how it behaves: /transcribe_all turns every new voice message into text, and sending it again switches that off.
  3. With that off, reply to any voice message, video note or supported audio file with /transcribe and Voicy answers that one message only.
  4. Add /silent to hide the status messages so the chat only sees the final text, and /lock to let only group admins use the commands.

Donations are per chat, so a group is activated by sending /donate inside that group.

In a chat Voicy is not a member of

Reply to a voice message, video note or supported audio or video file with @voicybot. Voicy answers in that reply through Telegram's Guest Mode, and when the text is longer than one reply it says so and suggests adding Voicy to the chat or messaging it directly for the full text.

The accepted extensions are .3gp, .3gpp, .aac, .aif, .aifc, .aiff, .amr, .avi, .flac, .m4a, .m4b, .m4v, .mka, .mkv, .mov, .mp3, .mp4, .mpeg, .mpg, .oga, .ogg, .opus, .wav, .wave, .weba, .webm and .wma. A document without one of them is still accepted when Telegram reports an audio or video type for it. /files switches audio files, videos and documents off for a chat, which keeps a group that shares a lot of music from being transcribed; voice messages and video notes are not affected.

Limits worth knowing

  • File size: up to 100 MB (104,857,600 bytes). A file of 104,857,601 bytes is refused with a message saying Voicy does not support files over 100 MB.
  • Queue: a chat that has not been activated can have 10 messages waiting at a time; the eleventh gets a "too many audio messages waiting" reply until the first ones finish.
  • Repeats: when the same Telegram file is transcribed again within 10 days, Voicy reuses the earlier text instead of running it again.
  • Language: the bot's menus speak English, German, Spanish, Portuguese, Russian and Ukrainian (/language). The speech itself is recognised by Whisper, which detects the spoken language unless a job names one.

What it costs

Voicy runs speech recognition on its own GPU computers, so each chat is activated once with a donation: Telegram Stars tiers, a card through Stripe, or any amount of at least $6.99 by sending, for example, /donate 15.69. Donations are per chat, not per person. Subscribers of the @golden_borodutch channel get 50 transcriptions for free before they need to activate a chat.

What was checked, and how

Checked on 2026-11-05 against the bot's source at commit ec9d855 (the main branch that day) with Node.js 22.23.4.

We read the handlers behind each step above, the English texts the bot sends, and the checks for file type and size. We then ran the bot's own file-type check and size check on 15 sample messages, and the table and the 100 MB line above are what they printed. For example, a message whose document is named x.OGG was accepted, x.pdf, x.txt and a.zip were ignored, and 104,857,600 bytes passed while 104,857,601 did not. We did not send a voice message through the live bot from this machine, so the timing of a real transcription and its accuracy are not measured here; the source is on GitHub if you want to read the same code.

Questions

Can I turn a Telegram voice message into text without installing anything?

Yes. Voicy is a Telegram bot, so there is nothing to install: open @voicybot, or reply to the voice message in your own chat with @voicybot in the message, and it answers with the text.

How do I turn voice messages in a group chat into text?

Add @voicybot to the group. It can turn every voice message into text, or only the ones someone replies to with /transcribe. /transcribe_all switches between the two.

Which files can Voicy turn into text?

Voice messages, round video messages, audio files and videos, and documents whose name ends in a common audio or video extension such as .ogg, .opus, .mp3, .m4a, .flac, .wav, .mp4 or .mov. Anything over 100 MB is refused.

Does Voicy cost anything?

Each chat is activated once with a donation, in Telegram Stars or by card, because the speech recognition runs on GPUs we pay for. Send /donate in the chat you want to activate; a group needs its own. Subscribers of the @golden_borodutch channel get 50 transcriptions for free.

Is the text accurate?

Voicy uses Whisper, an open-source model trained on about 100 languages, and the status message says when the text is still a draft. We haven't published an accuracy benchmark, so check names and numbers against the audio.
