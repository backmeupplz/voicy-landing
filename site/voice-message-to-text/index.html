How to turn a Telegram voice message into text

Forward any voice message or round video note to @voicybot in Telegram, add the bot to a group chat, or reply to a voice message in another chat with @voicybot. Voicy runs Whisper (large-v3) on our own GPUs, auto-detects around 100 spoken languages, accepts media up to 100 MB (104,857,600 bytes), and splits transcripts past 4,000 characters across follow-up replies. Audio files, videos, and media documents work too once you enable them with /files.

Checked on November 26, 2026 against Voicy's source: Voicy is not free because we pay for the GPUs running speech recognition. Each chat activates with a one-time donation via /donate (from 300 Telegram Stars, $6.99 by card, or tokens), and @golden_borodutch subscribers get 50 free transcriptions per user first. Unlike Telegram Premium's built-in transcription button, Voicy transcribes every voice message in a group automatically, handles audio and video files up to 100 MB, and runs an open-source MIT codebase.

Open in Telegram

In a private chat

  1. Open @voicybot in Telegram and tap Start.
  2. Record or forward a voice message or round video note. To transcribe audio files, videos, or media documents, send /files first because new chats start with files switched off.
  3. Voicy posts a processing status line, updates it with draft text while Whisper runs, and replaces it with the final transcript. Any transcript longer than 4,000 characters continues in follow-up messages.
  4. If the chat is not activated yet (and you are not using your 50-transcription @golden_borodutch allowance), Voicy replies with activation details. Send /donate whenever you want to pull up the payment buttons.

In a group chat

  1. Add @voicybot to the group.
  2. New groups start with automatic transcription turned on, so Voicy transcribes every incoming voice message and video note. Send /transcribe_all if you want to switch to manual mode instead, and send it again to turn auto-mode back on.
  3. In manual mode, reply to any voice message, video note, or supported audio or video file with /transcribe to transcribe just that message.
  4. Use /silent to skip status updates and timecodes (it also stays quiet when no speech is detected), /lock to limit bot commands to group admins, and /promos off if admins want to disable the occasional button for our other bots (shown at most once a week per group).

Activation is per chat, so send /donate inside the group to activate it there.

In a chat Voicy is not a member of

Reply to a voice message, video note, or supported audio or video file with @voicybot. Voicy answers inline through Telegram's Guest Mode, even if /files has never been run in that chat. Guest Mode fits one 4,000-character reply; when a transcript is longer, Voicy trims the end and tells you to add the bot or message it directly for the full text.

New chats leave files turned off so music-heavy groups do not fill up with transcripts; sending /files toggles them on or off. Replying directly to a supported file with /transcribe or mentioning @voicybot in Guest Mode transcribes it either way.

Limits worth knowing

  • File size: up to 100 MB (104,857,600 bytes). At 104,857,601 bytes, Voicy rejects the file and replies that files over 100 MB are not supported.
  • Transcript length: regular replies split every 4,000 characters. Guest Mode replies are capped at one 4,000-character message.
  • Queue: an unactivated chat can have up to 10 active jobs waiting at once; the eleventh receives a queue-full reply until earlier messages finish. Activated chats (and requests from a user whose private chat is activated) skip this cap, and concurrent duplicates of the same Telegram file are merged into one job.
  • Cache and cleanup: resending the same Telegram file within 10 days returns the cached transcript immediately instead of running Whisper again (and does not spend one of your 50 free transcriptions). On the worker, each job's downloaded media and transcript file are deleted from disk right after delivery.
  • Languages: /language changes the bot's menu language across 6 options (English, German, Spanish, Portuguese, Russian, and Ukrainian). Whisper always auto-detects the spoken language across roughly 100 languages; there is no command to force a recognition language.

What it costs

Because speech recognition runs on our own GPU workers rather than a free third-party tier, each chat needs a one-time donation to stay active. Send /donate in the chat you want to turn on: the built-in buttons offer Telegram Stars tiers (300, 500, or 1,000 Stars) and Stripe card tiers ($6.99, $9.99, $12.99, or $15.99), or you can pick a custom card amount from $6.99 up with a command like /donate 15.69, or send at least $6.99 in tokens to borodutch.eth. Donations activate one chat at a time, so a private chat and a group activate separately. Subscribers to @golden_borodutch get 50 free transcriptions per user before activating a chat.

Questions

Can I turn a Telegram voice message into text without installing anything?

Yes. Voicy runs inside Telegram with nothing to install: forward a voice message or round video note to @voicybot, add it to a group, or reply to a voice message in another chat with @voicybot through Telegram Guest Mode.

How do I turn voice messages in a group chat into text?

Add @voicybot to the group. New groups transcribe every incoming voice message automatically by default; run /transcribe_all to switch to reply-only mode where Voicy waits for someone to reply with /transcribe.

Which files can Voicy turn into text?

Voice messages, round video notes, audio and video files, and documents with 27 common audio or video extensions including .ogg, .opus, .mp3, .m4a, .flac, .wav, .mp4 and .mov, up to 100 MB (104,857,600 bytes). Audio files, videos and documents stay off in a new chat until someone sends /files, while voice messages and video notes work right away.

Does Voicy cost anything?

Voicy is not free because Whisper runs on our own GPUs. Each chat activates with a one-time donation via /donate (from 300 Telegram Stars, $6.99 by card through Stripe, or tokens to borodutch.eth). Subscribers to @golden_borodutch get 50 free transcriptions per user before activating a chat.

Is the text accurate?

Voicy runs open-source Whisper (large-v3), which auto-detects about 100 spoken languages, and labels draft replies while audio is still processing. We have not published an accuracy benchmark, so double-check names and numbers against the recording.
