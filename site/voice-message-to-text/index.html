How to turn a Telegram voice message into text

Forward the voice message to @voicybot in Telegram, or drop the bot into a group and reply with /transcribe. Voicy sends back the transcript moments later. There's nothing to install, and it handles round video notes too, plus audio and video files once you turn them on with /files.

Checked on November 9, 2026: Voicy runs speech recognition on GPUs we pay for, so you activate each chat once with a donation before it transcribes. Until then it replies with donation options. Telegram Premium builds transcription right into the app if you already pay for that subscription.

Open in Telegram

In a private chat

  1. Open @voicybot in Telegram and tap Start.
  2. Record or forward a voice message. If you want to transcribe an audio or video file instead, run /files first; new chats start with files switched off so Voicy ignores them until you flip it on.
  3. Voicy posts a status line, streams a draft while it processes, and replaces it with the final transcript. Anything past 4,000 characters splits across multiple messages.
  4. If the chat isn't activated yet, Voicy replies with donation options instead. Run /donate to pull them up anytime.

In a group chat

  1. Add @voicybot to your group.
  2. Pick a mode: /transcribe_all transcribes every new voice message automatically, and running it again switches auto-mode back off.
  3. With auto-mode off, reply to any voice message, video note, or supported audio file with /transcribe to transcribe just that message.
  4. Use /silent to skip status messages and only post the finished text, and /lock to restrict commands to group admins.

Activations are per chat, so run /donate inside the group to activate it there.

In a chat Voicy is not a member of

Reply to a voice message, video note, or supported audio or video file with @voicybot. Voicy responds inline through Telegram's Guest Mode. If the transcript won't fit in a single reply, it tells you to add the bot to the chat or message it directly for the full text.

Accepted file extensions: .3gp, .3gpp, .aac, .aif, .aifc, .aiff, .amr, .avi, .flac, .m4a, .m4b, .m4v, .mka, .mkv, .mov, .mp3, .mp4, .mpeg, .mpg, .oga, .ogg, .opus, .wav, .wave, .weba, .webm, and .wma. A document without one of those extensions still goes through if Telegram tags it with an audio or video MIME type. New chats leave files turned off so music-heavy groups don't get spammed with transcripts: Voicy stays quiet on files until someone runs /files, and running /files again turns them back off. Voice messages and video notes always work, and replying directly to a supported file with /transcribe or @voicybot transcribes it either way.

Limits worth knowing

  • File size: up to 100 MB (104,857,600 bytes). At 104,857,601 bytes Voicy rejects it and tells you files over 100 MB aren't supported.
  • Queue: an unactivated chat can queue up to 10 messages at once; the eleventh gets a "too many audio messages waiting" reply until earlier ones clear.
  • Repeats: resend the same Telegram file within 10 days and Voicy returns the cached transcript instead of running Whisper again.
  • Language: menus come in English, German, Spanish, Portuguese, Russian, and Ukrainian (/language). Whisper auto-detects the spoken language unless you specify one.

Questions

Can I turn a Telegram voice message into text without installing anything?

Yes. Voicy runs inside Telegram with nothing to install: forward a voice message to @voicybot, or reply to it in your own chat with @voicybot, and it sends back the text.

How do I turn voice messages in a group chat into text?

Add @voicybot to the group. It can transcribe every voice message automatically or only the ones someone replies to with /transcribe, and /transcribe_all toggles between the two.

Which files can Voicy turn into text?

Voice messages, round video notes, audio and video files, and documents with common audio or video extensions like .ogg, .opus, .mp3, .m4a, .flac, .wav, .mp4, or .mov. Anything over 100 MB is rejected. Audio, video, and document files stay off in new chats until someone sends /files, while voice messages and video notes work out of the box.

Does Voicy cost anything?

Each chat is activated once with a donation (Telegram Stars or card) to cover the GPUs running speech recognition. Send /donate in whichever chat or group you want to activate. @golden_borodutch channel subscribers get 50 transcriptions free.

Is the text accurate?

Voicy runs Whisper, an open-source model covering about 100 languages, and marks draft output in its status line. We haven't published an accuracy benchmark, so double-check names and numbers against the recording.
