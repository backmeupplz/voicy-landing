Voicy

Add @voicybot to a Telegram group chat and it replies to every voice message with its text, so everyone can read along instead of pressing play.

Open in Telegram

Questions

How do I turn Telegram voice messages into text?

Send a voice message to @voicybot in a private chat, or add it to a group. It replies to each voice message with its text.

How does it work in groups?

A group can have Voicy turn every voice message into text, or only the ones someone replies to with /transcribe. /transcribe_all switches between the two, and /silent hides the status messages so only the text is posted.

What can it transcribe?

Voice messages and audio files in .ogg, .flac, .wav and .mp3, up to 100 MB. Speech recognition runs on Voicy's own computers with Whisper, an open-source model trained on about 100 languages.

What does it cost?

Speech recognition takes GPU time, so each chat is activated once with a donation, in Telegram Stars or by card: send /donate in the chat you want to activate. Donations are per chat, so a group needs its own. Subscribers of the @golden_borodutch channel get 50 transcriptions for free.

Is it open source?

Yes. The code is on GitHub under the MIT license, along with the worker that runs the speech recognition.
